# Documentation boundaries & attribution

## Credit and scope
OverTheWire Bandit is maintained by the [OverTheWire community](https://overthewire.org/). This repository is an independent learning portfolio and is not affiliated with OverTheWire.

## No spoilers or credentials
To respect [the game rules](https://overthewire.org/rules/), this repository avoids:
- Level passwords and credentials
- Exact challenge answer paths or filenames used to retrieve credentials
- Direct solutions or step-by-step level walkthroughs
- Unredacted transcripts containing challenge secrets

Instead, it documents broadly transferable Linux concepts, setbacks, research decisions, troubleshooting habits and learning reflections.

## Provenance
The learner performed the terminal exercises and gathered outside documentation. Some conceptual explanations, project organization and writing were developed with ChatGPT assistance. This distinction is intentional: the purpose is to represent the actual learning process, not to imply expertise or authorship that has not been demonstrated.

## Future contributions
As the lab continues, add general lessons and sanitized evidence only. Check each image and pasted log for passwords, usernames, private identifiers, and other sensitive content prior to committing.
